# Tomato Timer

A focused, account-free Pomodoro timer built with plain HTML, CSS, and JavaScript.

## Features

- Focus, short-break, and long-break modes
- Configurable durations and long-break interval
- Optional automatic stage transitions
- Completion chime and desktop notifications
- Keyboard controls: Space to start or pause, R to reset, and S to skip
- Settings and daily completion count stored locally in the browser
- Responsive layout for desktop and mobile

## Privacy

The app has no analytics, accounts, cookies, advertising, or network requests. Settings and session counts remain in the browser's local storage.

## Run locally

Open `index.html` directly or serve the repository with any static file server.

## Deploy

The included workflow deploys the repository to GitHub Pages after Pages is enabled for the repository.
